# Diseño

Canvas aprobado de la plataforma (10 tableros, versión móvil y escritorio):
https://claude.ai/artifact/AyD1SjGiCmkr1U2gGJmMBD

Vocabulario visual: señales de tránsito. Rombo amarillo para trampa, azul o verde para el autor, rojo para error.
Botones con sombra dura. Tipografías Overpass y Atkinson Hyperlegible.
El frontend se implementa en código a partir de este canvas.
